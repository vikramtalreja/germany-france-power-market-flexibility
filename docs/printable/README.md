# Printable master guide

Revision: **21 October 2026, revision 2**.

Download [Power_Market_BESS_Project_Guide.pdf](Power_Market_BESS_Project_Guide.pdf). Open the PDF on GitHub and click **Download raw file**. Print A4, preferably double-sided.

Includes all project concepts and findings, ML diagnosis, continuous SOC operation, intraday accounting examples, data acquisition status and the procedure for using incoming auction data. Intraday examples are synthetic; historical intraday performance is not yet established.

Source: [project-learning-guide.md](../project-learning-guide.md). Build: `python scripts/build_project_guide.py` (requires reportlab). Update the source and PDF together at every milestone. Previous revisions remain in Git history.
